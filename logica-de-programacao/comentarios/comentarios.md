# COMENTÁRIOS
Não são executados no programa, tem como objetivo, agir como lembrete ou auxilio que facilita a leitura do código e para dar manutenção. Existem comentários **em linha única e bloco**.

### Comentário de linha única
 - Usado para fazer comentários curtos. Utilizamos as duas barras e escrevemos o que desejamos.

### Exemplo
```
// Este é um comentário de uma linha
escreva("Olá, mundo!") // Também posso comentar aqui na frente
```

### Comentário de bloco
 - Usado para textos longos ou para desativar várias linhas de código de uma só vez. Utilizamos para iniciar o bloco de comentário uma barra com asterisco  e escrevemos o que desejamos e fechamos o bloco de comentário um asterisco com barra.

### Exemplo
```
/*
   Este é um comentário de bloco.
   Posso escrever várias linhas aqui dentro 
   sem que o programa dê erro.
*/
```
