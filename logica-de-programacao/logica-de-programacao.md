### ALGORITMOS 
É uma sequência de passos para resolver um problema. A sequência de
passos altera os resultados dependendo da ordem, são lidos de cima para baixo.

#### 🔗 Links para estudar algoritmos
🌐 Online -[https://studio.code.org/](https://studio.code.org/)

### FLUXOGRAMA
É uma ferramenta utilizada pa representar graficamente o algoritmo
(Fluxo de Dados). Podemos entender como uma documentação dos passos necessários para
a execução de um processo qualquer.

#### 🔗 Links para estudar fluxograma
💾 Download -[http://www.flowgorithm.org/download/index.html](http://www.flowgorithm.org/download/index.html)
