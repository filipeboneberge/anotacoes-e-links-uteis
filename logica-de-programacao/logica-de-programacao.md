# 👨‍💻 LÓGICA DE PROGRAMAÇÃO
 É solucionar problemas buscando trazer sequência de ações(Algoritmo) que o computador entenda.

### PORTUGOL
Pseudolimguagem que permite desenvolver algoritmos estruturados em Português de forma simples e intuitiva, independente da linguagem de programação.

#### 🔗 Links materiais complementares
 - Variáveis
 - Constantes
 - Tipos de dados
 - Operadores aritméticos
 - Expressão aritmética
 - Expressões literais
 - Operadores de comparação ou lógico
 - Concatenação
 - Tomada de decisão
 - Estrutura de repetição
 - Comentários
 - Matriz e Vetores


#### 🔗 Links para estudar lógica de programação

💾 Download -[https://univali-lite.github.io/Portugol-Studio/](https://univali-lite.github.io/Portugol-Studio/)


### ALGORITMOS 
É uma sequência de passos para resolver um problema. A sequência de
passos altera os resultados dependendo da ordem, são lidos de cima para baixo.

#### 🔗 Links para estudar algoritmos
🌐 Online -[https://studio.code.org/](https://studio.code.org/)


### PSEUDOCÓDIGOS 
É uma forma mais simples e entendida de escrever algoritmo.

### FLUXOGRAMA
É uma ferramenta utilizada pa representar graficamente o algoritmo
(Fluxo de Dados). Podemos entender como uma documentação dos passos necessários para
a execução de um processo qualquer.

#### 🔗 Links para estudar fluxograma
💾 Download -[http://www.flowgorithm.org/download/index.html](http://www.flowgorithm.org/download/index.html)
