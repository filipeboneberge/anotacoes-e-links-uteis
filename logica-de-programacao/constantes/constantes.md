# CONSTANTES
É um identificador de dados cujo valor não muda durante a execução do programa. Diferente das [variáveis](../variaveis/variaveis.md), que podem ter seus valores alterados, as constantes garantem que valores fixos (como números matemáticos, configurações, ou menus) não sejam corrompidos acidentalmente. 

### Principais características
 - **Imutabilidade:** O valor atribuído no início permanece o mesmo até o fim.

 - **Declaração:** Utiliza-se a sintaxe **[const] [tipo] [nome] = [valor]**


 - **Convenção:** Recomenda-se o uso de letras maiúsculas para destacar que é um valor fixo.

### Exemplo
```
const real PI = 3.14159
const inteiro MAX_TENTATIVAS = 3
```
