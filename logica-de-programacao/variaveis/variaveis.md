# VARIÁVEIS
São espaços na memória capaz de reter e representar um valor ou esxpressão, podendo ser alterado durante a execução do algoritmo ou programa. 

### Declaração e Atribuição
A declaração de uma variável deve ser feita antes de ser utilizada. É possível atribuir um valor inicial no momento da declaração.

A declaração segue o formato **[tipo] [nome_variavel] = [valor]** 

Os principais [tipos de dados](../tipos-de-dados/tipos-de-dados.md) são: inteiro, real, cadeia, caracter e lógico.

### Regras para Nomes de Variáveis
- Devem começar com uma letra ou underline (_).
- Não podem ser palavras reservadas da linguagem (ex: se, entao, inteiro, ...).
- Não podem conter espaços ou caracteres especiais (exceto underline).

### Exemplo
```
inteiro idade = 20
real salario = 1500.50
cadeia nome = "Ana"
caracter aceito = 'S'
logico ativo = verdadeiro
```
