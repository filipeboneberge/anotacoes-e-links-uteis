# OPERADORES DE COMPARAÇÃO OU LÓGICO
É construída utilizando operadores relacionais para comparar valores (geralmente numéricos), resultando em um valor lógico: **verdadeiro** ou **falso**.

### Operadores Relacionais
 - **( == )  Igual a:** Verifica se dois valores são iguais.
 - **( != )  Diferente de:** 
 - **( > )  Maior que:**
 - **( < )  Menor que:**  
 - **( >= )  Maior ou igual a:** 
 - **( <= )  Menor ou igual a:** 

Essas expressões são a base para [estruturas de decisão](../tomada-de-decisao/tomada-de-decisao.md), como o comando ( se ), que executa um bloco de código apenas se a condição for verdadeira.
 ### Exemplo
```
se (idade >= 18)
se (nota < 5.0)
se (10 != 5)
```
