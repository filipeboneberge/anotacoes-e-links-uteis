# OPERADORES ARITMÉTICOS
Os operadores aritméticos permitem realizar cálculos matemáticos básicos e complexos.

### Principais Operadores Aritméticos
 - **( + ) Adição:** Soma dois valores.
 ### Exemplo
```
10 + 5
 a + b
```
 - **( - ) Subtração:** Subtrai dois valores.
 ### Exemplo
```
10 - 5
 a - b
```
 - **( * ) Multiplicação:** Multiplica dois valores.
 ### Exemplo
```
10 * 5
 a * b
```
 - **( / ) Divisão:** Divide  dois valores.
 ### Exemplo
```
10 / 5
 a / b
```
 - **( % ) Resto da divisão:** Retorna o resto de uma divisão inteira.
 ### Exemplo
```
10 % 5 = 0
10 % 3 = 1
```
 - **( ^ ) Potenciação:** Eleva um número a uma potência (geralmente mat.potencia(base, expoente)). incluída na biblioteca Matematica.
 ### Exemplo
```
2 ^ 3
inclua biblioteca Matematica --> mat
mat.potencia(base, expoente)
```
### Operadores de Atribuição Composta
Existem formas abreviadas para atualizar [variáveis](../variaveis/variaveis.md):
 - **( += ) Soma e Atribui:** É o mesmo que  ( a = a + 2 )
 ### Exemplo
```
a += 2
``` 
 - **( -= ) Subtrai e Atribui:** É o mesmo que  ( a = a - 2 )
 ### Exemplo
```
a -= 2
``` 
 - **( *= ) Multiplica e Atribui:** É o mesmo que  ( a = a * 2 )
 ### Exemplo
```
a *= 2
``` 
 - **( /= ) Divide e Atribui:** É o mesmo que  ( a = a / 2 )
 ### Exemplo
```
a /= 2
``` 
 - **( %= ) Resto e Atribui:** É o mesmo que  ( a = a % 2 )
 ### Exemplo
```
a %= 2
```
