# CONCATENAÇÃO
Faz união de textos ( cadeia ), [variáveis](../variaveis/variaveis.md) ou [constantes](../constantes/constantes.md), geralmente realizada através do operador de adição ( + ) no [Portugol Studio](../logica-de-programacaos.md#portugol), podendo ser outro operador dependendo da linguagem de programação, os mais comuns são: **( , ) virgula** e **( . ) ponto**.

Permite juntar frases fixas com valores de variáveis ou constantes, podendo assim exibir mensagens dinâmicas e personalizadas ao usuário.

### Operadores Relacionais
 - **( == )  Igual a:** Verifica se dois valores são iguais.
 - **( != )  Diferente de:** 
 - **( > )  Maior que:**
 - **( < )  Menor que:**  
 - **( >= )  Maior ou igual a:** 
 - **( <= )  Menor ou igual a:** 

Essas expressões são a base para [estruturas de decisão](../tomada-de-decisao/tomada-de-decisao.md), como o comando ( se ), que executa um bloco de código apenas se a condição for verdadeira.
 ### Exemplo
```
se (idade >= 18)
se (nota < 5.0)
se (10 != 5)
```
