# EXPRESSÕES LITERAIS
São expressões com [constantes](../constantes/constantes.md) e [variaveis](../variaveis/variaveis.md) que tem como resultado valores literais. Utilizamos na atribuição de valor para uma constante ou variável.

### Propriedades de uso
 - **Atribuição:** ( "Maria" ) é o valor literal.
 ### Exemplo
```
nome = "Maria"
``` 

- **Exibição:** ("O resultado é: " e 10 são literais).
 ### Exemplo
```
escreva("O resultado é: ", 10)
``` 

- **Comparação:** ( 'M' ) é o valor literal.
 ### Exemplo
```
se (sexo == 'M')
```
