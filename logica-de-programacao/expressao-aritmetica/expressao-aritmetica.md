# EXPRESSÃO ARITMÉTICA
Utilizam [operadores aritméticos](../operadores-aritmeticos/operadores-aritmeticos.md) podendo envolver [constantes](../constantes/constantes.md) e [variaveis](../variaveis/variaveis.md).

### Regras de Precedência
As operações seguem a ordem matemática convencional:

  - **( ( ) ) Parêntese**
  - **( ^ ) Potenciação**
  - **( * ) Multiplicação**
  - **( / ) Divisão**
  - **( + ) Adição**
  - **( - ) Subtração**

 ### Exemplo
 Expressão aritmética com uso de parênteses para precedência
```
media = (nota1 + nota2) / 2
```
