# TIPOS DE DADOS
Definem o tipo de valor que uma [variável](../variaveis/variaveis.md) ou [constante](../constantes/constantes.md) pode armazenar, garantindo o armazenamento correto de informações na memória.

### Principais Tipos de Dados
- **inteiro:** Armazena números inteiros (positivos ou negativos, sem casas decimais). 
### Exemplo
```
inteiro idade = 20
```

 - **real:** Armazena números com casas decimais. 
### Exemplo
```
const real PI = 3.14159
```

 - **cadeia:** Armazena sequências de caracteres (textos).
### Exemplo
```
cadeia nome = "Ana"
```

 - **caracter:** Armazena um único caractere (apenas uma letra ou símbolo entre aspas simples). 
### Exemplo
```
const caracter SEXO = 'M'
```

 - **logico:** Armazena apenas dois valores possíveis: verdadeiro ou falso
### Exemplo
```
logico ativo = verdadeiro
```
